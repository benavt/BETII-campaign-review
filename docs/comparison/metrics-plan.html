1. Recover native confidence before refolding

planned · 180 metric values

Recover pTM, ipTM and mean pLDDT from matching native confidence files. Our complexes: 40 Boltz2 Exact, 4 AF3 and 4 OpenDDE cells lack each of the three metrics (144 values). Monomers: six mean pLDDT gaps in our panel and 30 in Jokent. Verify native model/rank hashes, actual units and averaging basis. Compute Cα means from native coordinates only when their pLDDT encoding is documented.

No external credits expected; bounded local validation/calculation. If a native scalar was never retained, label it not reported and assess an explicit successor fold only after archive recovery is exhausted.

2. Calculate full-chain OpenFold ipSAE

planned · 80 complexes

Use the exact selected native models and their matched PAE tensors for all 40 models in each group, with one pinned ipSAE recipe and common full-chain directional-minimum definition. Validate PAE sequence/residue order and cutoff settings. If a matched PAE is absent, record that dependency; coordinate-only estimates do not substitute for ipSAE.

No external credits expected for saved-PAE calculation; a missing PAE may require a separately scoped native successor.

3. Add the same working-pocket assessment to Jokent

planned · 10 BRD3 Exact complexes

Reuse the existing documented 12-residue working-pocket mask, verify its mapping onto the canonical BRD3 receptor and calculate the same mean nearest binder heavy-atom distance in Å. Bind each result to its native coordinate hash. A working pocket is a geometric assessment, not an inferred original design-hotspot mask.

Local coordinate calculation; no external credits.

4. Complete remaining selected DeltaForge comparisons

planned, spending not authorized by this plan · 3 Exact Kds

miniprotein_879 needs BRD2, BRD4 and BRDT. Reconcile the previous halted approved run using free account/ledger reads and check for saved results before any submission. Retain the existing BRD3 Kd and use only its three selected Exact comparator models. Obtain a current exact quote and explicit batch approval before any paid operation; no automatic retries.

Planning estimate: 75 credits for 3 × the previously verified 25-credit unit charge. This is not a current provider quote or approval.

5. Recover missing native dimer conditions

planned; recover first · 30 conditions / 150 native rank slots

Our ten sequences have public OpenFold dimers, while Jokent has all four native dimer methods. Locate and validate our 10 × 3 missing Boltz2 Exact, AF3 and OpenDDE conditions, retaining all five native ranks. Publish saved results first. If absent, prepare 30 explicit homodimer conditions (150 native outputs) through the native folding adapters, with a separate resource/cost review.

Saved-result recovery uses no credits. New folds depend on the actual native route and require a scoped plan and any applicable paid quote.

6. Resolve scope-specific and engine-specific blanks

definition / provenance review

Retain the eight designed-core ipSAE observations separately; do not copy full-chain ipSAE into core fields. A core metric needs an explicitly documented residue mask. Recover native confidence ranking scores only where each engine reports its exact definition. Mark monomer interface metrics not applicable. Kds from Exact coordinates are never transferred to another folding method. NetSolP-D is already complete for both groups.

No external credits for definitions and source recovery. Extending PCANN to all three additional complex methods would be a separate optional 240-model local batch, outside the Exact-only parity scope.

7. Validate and publish the completed matrix

planned

Require complete sequence/construct/isoform/rank identities, native and metric-source hashes, matching scorer calibration, finite values, unit/PAE checks and unchanged human review records. Recalculate selectivity separately for each compatible scorer/method, keep missing values explicit, then refresh the comparison page, source JSON and CSVs.

No scientific/provider requests during publication checks.
